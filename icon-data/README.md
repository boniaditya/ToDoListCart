# Bundled offline icon collections

This extension ships the complete Iconify JSON exports for the following free
collections. The files are loaded only from the installed extension package via
`chrome.runtime.getURL()`; the icon picker does not access online APIs.

- Tabler Icons (`tabler.json`) — MIT License, see `LICENSE-TABLER.txt`.
- Material Design Icons (`mdi.json`) — Apache License 2.0, see
  `LICENSE-MDI.txt`.

The two collections contain more than 13,000 SVG icon definitions combined.
