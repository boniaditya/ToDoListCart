# ToDoListCart

A Chrome extension by boni aditya that turns a todo list into a compact shopping cart.

Create todo items as products, search by product name, browse department tabs, add products into the cart, and check them out when the work is done.

Version `8.0.0` adds custom categories, image upload/drop/paste support, priority toggles, MOQ, product dollar amounts, and richer account defaults.

## Load in Chrome

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Choose Load unpacked.
4. Select this folder.

Click the ToDoList Cart toolbar button to open the popup.
Click Full Tab in the popup to open the full-page cart workspace.
Click Products to open the product listing page, then Details on any product to view its description page.
Click Orders to review checked-out carts, or Account to update plugin settings.
